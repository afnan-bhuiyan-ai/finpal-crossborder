# Sources, data provenance and licences

## Project provenance

The user supplied `fintech-agent.zip` (FinPal Topic A). README and every `agent/*.py` file were inspected before implementation. The loop/provider interface, native Gemini replay, policy/confirmation/audit architecture, scenario command structure and documentation/test layout were copied or adapted. The Topic C intent router, synthetic fixtures, deterministic calculations, interface panels, tests and documentation were developed for this entry. The original archive contains no source licence. See [NOTICE](../NOTICE.md); the entrant should establish rights to supplied code before publication.

Every financial fixture is generated by `data/generate_data.py`. Names are fictional; account identifiers are synthetic; transaction descriptions include one deliberate hostile string for testing. Rates/history are invented, not scraped or sourced from any market. The providers' fee conventions and limits are invented. The USD 1,000 review threshold and USD 5,000 large-transfer parameter are synthetic heuristics, not regulatory claims. No competition branding asset is embedded in the app.

## Primary reference links

- [Google thought-signature guidance](https://ai.google.dev/gemini-api/docs/generate-content/thought-signatures): preserve signature-bearing response content in function-calling history. The original response object is retained and replayed; no provider private reasoning is displayed.
- [Google pricing](https://ai.google.dev/gemini-api/docs/pricing) and [model catalogue](https://ai.google.dev/gemini-api/docs/models): free-tier eligibility and alias availability are operator checks. Neither a key nor a listed model proves that a project is non-billed. The original latest-alias chain is preserved; no dated replacement was selected.
- [CFPB credit rebuilding education](https://www.consumerfinance.gov/consumer-tools/credit-reports-and-scores/how-to-rebuild-your-credit/): supports general discussion of secured cards, on-time payments and low credit utilisation. Its US context is not treated as global eligibility or legal advice; the app makes no score promise.
- [FATF FAQ](https://www.fatf-gafi.org/en/pages/frequently-asked-questions.html): background on identification, record keeping and transaction-review systems. This app implements no regulatory screening or legal thresholds.

References reviewed during the build on 20 October 2026. No source text, market data or regulatory thresholds were copied into fixtures.
